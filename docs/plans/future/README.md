# Future sprints

Sprints after the one in `next/`, one per folder: `future/SPRINT-NN/SPRINT.md` (with its group plans if it already
has them), numbered consecutively after next. Same canonical header as `next/SPRINT.md`. When next is activated
(`concertino start`), `future/SPRINT-(n+1)/` is promoted to `next/`. Preparing them does not activate them; their
dependencies on other projects go in `../DEPENDENCIES.md`.
