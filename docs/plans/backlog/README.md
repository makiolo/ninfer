# Backlog

Individual future plans, one per topic (`PLAN_<TOPIC>.md`), without a sprint. Each plan carries status, verified
state, options, phases or tasks with verifiable acceptance, dependencies, risks and open questions.
`concertino plan` refreshes them against the code and groups their tasks into `next/` or a `future/SPRINT-NN/`;
permanent vision documents (e.g. `ROADMAP.md`) are refreshed but never merged. `REVIEWS.md` records the plan reviews
(`concertino review`). List and status of each plan: board [index.md](../index.md).
