# Sprint archive

Each close keeps a complete dossier in `SPRINT-NN_<start>_<end>/`: plans, LAUNCH and prompts, sources and annexes,
done, every issue of the sprint, retrospective, USAGE, QUESTIONS and the move manifest. RELEASE is added later with
its own dates. Archived does not mean resolved: pending items link their live card. Other projects read this folder to
know whether a sprint is closed (`DEPENDENCIES.md`, condition `closed`).
